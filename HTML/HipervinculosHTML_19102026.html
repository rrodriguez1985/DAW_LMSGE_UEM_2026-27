Hipertextos o Hipervínculos en HTML5

Los hipervínculos o hipertextos en HTML5, son elementos característicos de las páginas web, puesto que
permiten que los documentos HTML se relacionen entre sí.
Un enlace sólo puede llevar a un destino, pero que enlces diferentes uede llevar al mismo destino.
El destino de un enlace puede ser un directorio, un archivo o un elemento (texto, tabla, imagen, etc.)
situado en la página web.

La estructura que presenta un hipervínculo es la siguiente:

  • Tenemos una etiqueta que se llama anchor (anclaje), definida por la etiqueta a.
    Esta etiqueta tiene apertura y cierre.
  • Está formado por el atributo href. que es donde va a a ir el enlace al que queremos direccionarnos.
    Siempre entre comillas dobles.
  • Un texto que irá entre la etiqueta de apertura y la de cierre, que es la que actuará como elemento
    de enlace para nuestros vínculos.

Pincha aquí para ver la oferta educativa de la UEM
Pincha aquí para ver los apuntes de Lenguaje de Marcas

Para poder abrir el hipervinculo de la página web en una nueva pestaña (es decir, en otra distinta),
utilizaremos el atributo target="_blank"
Importante: Cuando tratemos con documentos de cualquier tipo o formato, deberemos tener en cuenta
la ubicación de dónde estamos y hacia dónde vamos....
ES decir, tener en mente el siguiente esquema: si estoy a la misma altura del documento al que
queremos vincular, o si estoy por encima o por debajo de este...

Para poder poner un vínculo asociado a un correo electrónico, utilizaremos la misma estructura que
en los hipervínculos, sólo que añadiendo el atributo mailto.
