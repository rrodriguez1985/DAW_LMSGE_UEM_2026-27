Listas en HTML5

Las listas en HTML5 se organizan en tres tipos y sirven para organizar el texto con el fin de darle un formato más
claro y consiso.
  • Listas Ordenadas (ol):Listas ordenadas que van en orden.
    Las siglas ol, vienen dadas por OrderedList
  • Listas Desordenadas (ul): Listas desordenadas, es decir, no van en orden.
    Las siglas ul, vienen dadas por UnOrdered List
  • Listas de Definición (dl): Listas de definición. Las siglas dl, vienen dadas
    por Definition List.
Dentro de un elemento lista, sea del tipo que sea, podemos insertar cualquier tipo de elemento:
textos, imágenes, tablas, vídeos, audios, etc.
Por lo tanto, se pueden combinar listas ordenadas con desordenadas, y viceversa.

Listas Ordenadas (OL)

La estructura de una lista ordenada (ol), es la siguiente:
  • La lista esta formada por la etiqueta de apertura y cierre ol
  • Internamente, disponemos de una etiqueta li en la que pondremos los elementos a listar,
    es decir, el contenido de nuestra lista.
  • La etiqueta li irá siempre tanto en listas ordenadas como desordenadas, porque son parte de su
    estructura.

Ejemplo de Lista Ordenada
  1. Picachu
  2. Charmander
  3. Bulbasur
  4. Squitle
  5. Giratina

Listas Desordenadas (UL)

La estructura de una lista desordenada (ul), es la siguiente:
  • La lista esta formada por la etiqueta de apertura y cierre ul
  • Internamente, disponemos de una etiqueta li en la que pondremos los elementos a listar,
    es decir, el contenido de nuestra lista.
  • La etiqueta li irá siempre tanto en listas deordenadas como ordenadas, porque son parte de su
    estructura.

Ejemplo de Lista Desordenada
  • Windows 11
  • Linux Mint
  • Kali Linux
  • Debian
  • MacOS Yosemite

Formatear Listas Ordenadas y Desordenadas en HTML5

En HTML5, podemos formatear la apariencia de la estructura de las listas con el atributo type y start.
Con el atributo start, podemos indicar el orden en el que queremos empezar nuestra lista.
Con el atributo type, podemos indicar el tipo de icono que le queremos aplicar a nuestra lista.

Ejemplo de Lista Ordenada aplicando los atributos start y type

  1. Podemos utilizar letras en mayuscula (A)
  2. Podemos utilizar letras en minúcula (a)
  3. Podemos utilizar numeros normales (1,2,3,...)
  4. Podemos utilizar números romanos en mayusculas y minúsculas (i I ii II iii III iv IV, etc.
  5. Podemos utilizar start para indicar en qué posición queremos que comience.

Ejemplo de Lista Desordenada aplicando los atributo type

  • Podemos utilizar el tipo disc (viñetas redondas rellenas)
  • Podemos utilizar el tipo circle(viñertas redondas huecas)
  • Podemos utilizar square (cuadrados)

Listas de Definición

Las listas de definición, tienen una estructura totalmente distinta a las anteriores.
Tienen en este caso la siguiente estructura interna:
  • La etiqueta dl: Description List. Delimita la lista completa.
  • La etiqueta dt: Description Term. Delimitar el término de la lista
  • La etiqueta dd: Definition Description- Delimita la definición del término.

Ejemplo de Lista de Definición

dl
Crea la caja que contiene los items de la lista.
dt
Es el item que contiene un término a definir.
dd
Es el item que contiene la definición.

Listas anidadas en HTML

En HTML, podemos anidar diferentes tipos de listas combinando de esta manera listas ordenadas con desordenas y viceversa.
Suelen emplearse listas anidadas de hasta un 3er nivel.

Ejemplo de Lista Anidada:
  • CFGS DAW / DAM
    1. Lenguaje de Marcas
      • HTML5
      • CSS3
      • JavaScript (JS)
      • PHP
    2. Sistemas Informáticos
    3. Programación
    4. Bases de Datos
    5. Entornos de Desarrollo
    6. Itinerario para la Profesionalidad (ITPE)
  • CFGS ASIR
    1. Fundamentos de Hardware
    2. Lenguaje de Marcas
    3. Planificación y Administración de Redes
    4. Implantación de Sistemas Operativos
