Secciones en HTML5

Cuando vamos a crear una página web, debemos tener en cuenta, que esta puede estar dividia en distintas
secciones o partes, en donde alojaremos distinto contenido que queramos mostrar.
En tecnologías como HTML4, se utilizaban principalmente una serie de cajas o elementos
llamados div para poder insertar este tipo de información.
Estos div junto a CSS, se les asignaba un idenfiticador (id) o clases (class) para darles un nombre concreto, así como una
serie de atributos o características concretas.

el nombre como anteriomente se utilizaban, sino que ya existen etiquetas propias con los nombres asociados
a la estructura del documento HTML5.

¿Para qué sirve cada etiqueta HTML5?

Cabecera o Header

La etiqueta cabecera o header en HTML5, sirve para contener el título y/o elementos introductorios de nuestra página web. Es la parte superior deuna página o articulo.
Ejemplo: En un documento HTML5, podemos tener un header con un título que sea de nuestra página web, y un texto introductorio del mismo.
En el caso de una tienda online, podría ser el encabezado del mismo.

Menú de Navegación o Nav

En HTML5, podemos agrupar enlaces a otras páginas o apartados, a través de la etiqueta nav.
Con esta etiqueta por ejemplo, podemos crear un menú de una web, que permita llevarnos a las distintas secciones o apartados de la misma.
En el caso de una tienda online, podría ser como un índice de los apartados de la web o un menú de navegación entre secciones de esta.

Contenido Principal o Main

La etiqueta main, es la que va a contener todo el contenido centra de nuestra página web.
Importante: esta etiqueta no sustituye a la etiqueta body del documento HTML5, sino que va dentro de esta.
Recordar, esta etiqueta y apartado, es la parte más importante para el usuario de nuestra página web.

Apartado temático o Section

La etiqueta section, es una etiqueta en HTML5 que nos permite agrupar contenido relacionado con un tema, normalmente incluyen un título.
Ejemplo: Puede ser como un capítulo de un libro o la sección de un periódico.

Contenido Independiente o Article

Esuna etiqueta que permite agrupar contenido que tiene sentido por sí solo, como una noticia o publicación.
Por ejemplo, puede ser una noticia que puede leerse por separado.

Contenido Secundario o Aside

Sirve para agrupar contenido que tiene información complementaria al contenido principal.
Ejemplo: para mostrar información en un recuadro con una curiosidad...

Pie de página o Footer

Contiene información final como puede ser el autor, derechos de autor o enlaces relacionados.
Es lo que se conoce como la zona final de la página web

Otras etiquetas que podemos utilizar: address y hgroup

Otras de las etiquetas a tener en cuenta en HTML5 y que podemos utilizar con menor frecuencia, son address y hgroup.
address: Se utiliza para indicar los datos de contacto del autor o responsable del contenido.
hgroup: Se utiliza para agrupar un encabezado con un subtitulo o lema asociado.
Recordar: hgroup se suele utilizar para agrupar un título y un subtítulo, mientras que header se utiliza cuando hay metadados asociados al título.

Diferencias entre una etiqueta Div y Span

En HTML5, podemos a parte de encontrarnos con las etiquetas anteriormente comentadas, con dos etiequetas que podemos usar para nuestra estructura del
documento web.
Estas etiquetas son la etiqueta div y la etiqueta span
  • div: Esta etiqueta se utiliza para poder agrupar contenido en bloques.
    Cada div forma un bloque que normalmente empieza en una línea nueva.
  • span: Esta etiqueta se utiliza para agrupar una parte de una línea.

  • div: Se utiliza para agrupar bloques de contenido. Ejemplo: un recuadro de perfil
  • span: Se utiliza para agrupar parte deuna línea. Ejemplo: Una palabra coloreada.
Truco: div organiza bloques. Mientras que span permite trabajar con partes pequeñas de texto.
Hay que tener en cuenta, que ninguno aporta por sí mismo un significado específico.
