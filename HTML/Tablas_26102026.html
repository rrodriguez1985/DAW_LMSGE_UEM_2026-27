Tablas en HTML5

Cuando hablamos de tablas en HTML5, nos estamos refiriendo a un conjunto de celdas
donde podemos alojar distintos contenidos (imágenes, textos, vídeos, etc.)
Así, las características que presentan una tabla son las siguientes:
  • Definiremos tabla con la etiqueta de apertura y cierre table
  • La tabla estará dividida en filas definidas por la etiquea tr
  • Cada fila, estará dividida en celdas representadas por la etiqueta td
  • Las celdas pueden contener texto, imágenes, formularios, listas, otras tablas...

Elementos de una tabla

  • table: sirve para definir una tabla
  • caption: sirve para poder color un título a una tabla
  • align="top/bottom": es un atributo con el que podemos alinear en la tabla
    en la parte superior o inferior el título.
  • thead: Definir la cabecera de una tabla
  • th: Definie una celda como si fuera la cabecera de una tabla
  • tbody: Define el cuerpo de una tabla
  • tfood: Definir el pie de la tabla
  • tr: Define una fila de una tabla
  • td: Define una celda de una fila

Atributo Específicos para tablas: combinación de tablas

Para poder hacer combinación de tablas, utilizaremos unas propiedades
que son rowspan y colspan para combinar celdas de
la misma tabla.
  • rowspan: Sirve para combinar filas. Se utiliza indicando
    el número de filas que ocupa por celda.
  • colspan: Sirve par combinar columnas. Se utiliza indicando
    el número de columnas que ocupa una celda.

Propiedades de las celdas en las tablas

  • border: Establece el ancho del borde de la tabla exterior en px.
  • cellspacing: Especificar el espacio entre celdas de la tabla
  • cellpadding: Especificar el espacio entre el borde de una celda y su contenido.
